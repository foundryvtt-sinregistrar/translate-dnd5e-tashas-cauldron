# D&D 5e Tasha's Cauldron of Everything — Spanish (Babele)

Unofficial Spanish translation of the premium **Tasha's Cauldron of Everything** module for Foundry VTT 14 using Babele.

Requires Foundry VTT 14+, dnd5e 5.1.7+, Babele 2.7.5+, and the official `dnd-tashas-cauldron` module 3.0.0+.

This project is not affiliated with Wizards of the Coast or Foundry Gaming LLC and does not include the original premium module content.
