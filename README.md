# D&D 5e El Caldero de Tasha para Todo — Español (Babele)

Traducción no oficial al español del módulo premium **Tasha's Cauldron of Everything** para Foundry VTT 14 mediante Babele.

## Requisitos

- Foundry VTT 14+
- Sistema dnd5e 5.1.7+
- Babele 2.7.5+
- Módulo oficial `dnd-tashas-cauldron` 3.0.0+

## Instalación

Instala el manifiesto desde:

`https://raw.githubusercontent.com/foundryvtt-sinregistrar/translate-dnd5e-tashas-cauldron/main/module.json`

Este proyecto no está afiliado a Wizards of the Coast ni a Foundry Gaming LLC. No incluye el contenido del módulo premium original.
